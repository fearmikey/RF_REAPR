RF-REAPR (Reconnaissance, Evaluation, Analysis, and Penetration Reporting) is a comprehensive Android-based security auditing and network reconnaissance tool. Designed for security professionals and enthusiasts, it provides a suite of tools to analyze, map, and evaluate the security posture of network and radio frequency environments.

Features include:
- Guided Audit Workflows & Compliance Checklists
- Network Discovery, Port Scanner, & Interactive Topology Map
- Integrated Traffic Capture (PCAP) & Throughput Testing (iPerf3)
- Wireless Auditing (Bluetooth RSSI Finder, Wi-Fi Fingerprinting, RTL-SDR Spectrum Analysis)
- OSINT & Web Tools (Username/Phone OSINT, DNS, Certificates, EXIF Inspector)
- Physical & Hardware Tools (Magnetometer & HID Injector Payload Planner)
- Evidence Capture System with Local Retention & Export capabilities
- 100% FOSS, Offline-First & Privacy Preserving

Optional online integrations: some modules can query third-party, non-free network services (e.g. Shodan, Have I Been Pwned, AbuseIPDB, AlienVault OTX, NVD). These are only contacted when you use the corresponding tool, and several require your own API key. All core functionality works without them.

RF-REAPR is intended for educational and authorized security auditing purposes only.
